삼각형 넓이 문제 만들기

형태를 고르고, 밑변을 선택한 뒤, 밑변과 높이를 확인하면 넓이가 바뀝니다. 필요한 값은 숨겨서 문제로 만들 수 있습니다.

2밑변 선택

삼각형의 한 변을 누르면 그 변이 밑변이 되고, 알맞은 높이가 다시 계산됩니다.

밑변과 높이를 자연수로 입력하면 삼각형이 보입니다.

3밑변과 높이 길이 확인

선택한 밑변 0 cm
알맞은 높이 0 cm
4. 바뀐 넓이 0 ㎠

1삼각형 형태 선택

3길이 직접 조정

추천 적용: 밑변과 높이는 자연수만 입력하고, 넓이도 자연수가 되도록 밑변과 높이 중 적어도 하나는 짝수로 입력합니다.

4넓이 확인

값을 지우면 삼각형이 사라집니다. 알맞은 자연수를 다시 입력하면 삼각형이 나타납니다.

내가 만든 문제
